#ActorLoạiHành độngOutput / Gate

2 🤖 Claude Read Đọc DataModel/datamart_model.yaml: tìm bảng có cùng source_atomic; so sánh table_type; xác định reuse_status đề xuất (reuse / partial / new) —

4 👤 Human Approve Xác nhận reuse_status từng bảng: reuse / partial / new —
HLD · Phase 1 Bước 4–5 — Phân loại bảng + Thiết kế + Xuất file
#ActorLoạiHành độngOutput / Gate

3 🤖 Claude Review Self-review checklist: Section 1 (flowchart nodes/edges), Section 2 (hierarchy, bảng KPI, erDiagram), Section 3 (không có PENDING), Section 4 (reuse đầy đủ) —
