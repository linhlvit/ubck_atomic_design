YAML Parsing — Dual Format

📦 Real Format (production)

Detect: mapping key là dict ở root
source_type: physical_table | derived_cte | unpivot_cte
relationship: join definitions dạng objects
final_filter: list objects có clause_type + expression
select_fields: comma-separated string, smart split
unpivot_spec: value_columns, type_column, legs

🧪 Simple Format (tests)

Detect: mapping_id ở top-level
row_type: equivalent source_type
join_definitions: dạng list đơn giản
final_where / final_group_by dạng list strings
Cùng output: MappingFile dataclass thống nhất
Dễ viết fixtures, giảm boilerplate khi test
⚠️ Validation: thiếu mapping.id, table_name, alias, target_column → báo lỗi với row index + field name · Preserve order theo YAML

CTE Generation — 3 Loại

🗃️ Physical Table CTE
SELECT fields từ YAML · FROM dùng {{ ref('ods_fims_fundcompany') }}

dbt ref = namespace_subsystem_table
Subsystem parse từ mapping.id (segment sau dấu - cuối, trước .)

WHERE filter nếu field filter không null
🔗 Derived CTE
Merge: derived theo sau physical, alias khớp → gộp thành 1 CTE: SELECT physical + aggregation, GROUP BY

Chain: chuỗi derived → mỗi CTE reference alias CTE trước

Standalone: không match predecessor → CTE độc lập
↕️ Unpivot CTE
Sinh UNPIVOT expression · FOR...IN clause

Mỗi leg (column-label pair) trên 1 dòng riêng:
(IdNo, IdDate) AS 'BUSINESS_LICENSE'

Source từ alias physical CTE đứng trước
-- Physical Table CTE (có filter) WITH fu_co AS ( SELECT Id, Name, Capital FROM {{ ref('ods_fims_fundcompany') }} WHERE Status = 'ACTIVE' ), -- Derived CTE chain (fu_co → fu_co_agg) fu_co_agg AS ( SELECT FundId, COLLECT_LIST(NAMED_STRUCT('bsn_tp_codes', BuId)) AS bsn_tp_codes FROM fu_co GROUP BY FundId )

SQL Generation & Formatting

⚙️ 5 Transformation Rules (theo priority)

#1 {hash_id}(...) → surrogate_key_bigint
#2 transform + data_type → CAST(expr AS type)
#3 transform only → expr verbatim
#4 data_type only → CAST(NULL AS type)
#5 neither → NULL
+ Thêm AS target_column ở mọi case

✨ Formatting Rules

Leading comma style trong SELECT: dòng đầu không có comma, các dòng sau bắt đầu bằng ,
Alias alignment: pad expression sao cho tất cả AS thẳng cột
Indent 4 spaces: CTE body, JOIN clause
WHERE continuation: indent 8 spaces, AND ở đầu dòng
SQL keywords UPPERCASE: SELECT, FROM, WHERE, JOIN, CAST…
COLLECT_LIST/SET với NAMED_STRUCT → multi-line format

Error Handling Strategy

⚠️ Error Categories

FileNotFoundYAML path không tồn tại
YAMLParseErrorInvalid YAML syntax + line number
ValidationErrorMissing required field, row index
AliasErrorEmpty alias trên physical_table
UnresolvedRefderived_cte alias không tồn tại
UnpivotErrorZero column-label pairs
PatternMatchGlob không match file nào

✅ Handling Principles

Fail-fast per file, continue batch — không dừng toàn bộ xử lý
No partial output — hoặc SQL file hoàn chỉnh hoặc không ghi gì
Error context đầy đủ: file path + pipeline step + row/line number + description
Validation sớm trong parse — trước khi sinh SQL
CLI errors — exit ngay với non-zero exit code + message to stderr
9 pipeline steps · Mỗi step có error_step label
parsing → model_name → output_path → header → cte_building → select_generation → filter_generation → formatting → file_writing
